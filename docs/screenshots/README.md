# Screenshot Assets

Save your screenshots in this folder to make them render correctly in the project documentation:

*   `dashboard.png` — Main panel view of the chess assistant.
*   `custom_settings.png` — Granular sliders in Custom Presets mode.
*   `sf_mode.png` — Interface styling when Shadow Fiend Mode is activated.
*   `developer_mode.png` — Chrome Extensions Developer Mode page (`chrome://extensions/`) showing loaded unpacked folder.

The markdown guides in `docs/` reference these filenames directly!
