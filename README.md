## ♟ About

Knight Chess Helper is a modern browser-based chess analysis assistant powered by Stockfish WebAssembly.

Designed for analysis, training, opening preparation, and study, Knight focuses on speed, usability, and local-first architecture.

- Local engine processing
- Opening book support
- Real-time move suggestions
- Statistics tracking
- Modern interface
- Manifest V3 architecture

---

## ⚖️ Disclaimer

Knight is intended for educational purposes, game review, training, and chess improvement.

The extension performs calculations locally and does not rely on external engine servers.

Please use it responsibly and follow the rules of the platform you play on.

## 🚀 Installation

1. Download the latest release.
2. Extract the archive.
3. Open:

```text
chrome://extensions
```

4. Enable Developer Mode.
5. Click Load unpacked.
6. Select the extension folder.
7. Open Chess.com.
